
# Data Quality & Anomaly Detection

A Python project for profiling datasets, validating data quality,
detecting unusual records, and generating reports.

## Objectives

- Profile datasets and summarize their structure.
- Identify missing, duplicate, invalid, or inconsistent values.
- Flag unusual records using defined anomaly-detection rules.
- Generate reports that help users understand data-quality issues.

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- OpenPyXL
- Faker
- Pytest
- SQL

## Project Structure

- `data/raw/` - Original input datasets
- `data/processed/` - Processed and flagged datasets
- `src/` - Python source code
- `sql/` - SQL validation scripts
- `reports/` - Generated reports
- `tests/` - Automated tests
